# Moodle Stubs

PHP stub files for the [Moodle LMS](https://moodle.org/) codebase. Provides IDE autocompletion and static analysis support for Moodle's classes, functions, constants, and global variables — without requiring a full Moodle installation.

## Installation

```bash
composer require --dev michaelmeneses/moodle-stubs
```

To pin to a specific Moodle version:

```bash
composer require --dev michaelmeneses/moodle-stubs:^4.3
composer require --dev michaelmeneses/moodle-stubs:^5.0
```

## Configuration

### PHPStan

Add to your `phpstan.neon`:

```neon
parameters:
    scanDirectories:
        - vendor/michaelmeneses/moodle-stubs/stubs
```

### Psalm

Add to your `psalm.xml`:

```xml
<psalm>
    <stubs>
        <dir name="vendor/michaelmeneses/moodle-stubs/stubs"/>
    </stubs>
</psalm>
```

### Rector

Rector uses PHPStan internally. Add the PHPStan configuration above and Rector will pick it up automatically.

### PhpStorm

Stubs are detected automatically via Composer. If not, mark the `vendor/michaelmeneses/moodle-stubs/stubs` directory as a Sources Root.

## What's Included

- **Classes, interfaces, traits, and enums** — full declarations with method signatures, type hints, and PHPDoc
- **Functions** — all procedural functions from Moodle's libraries
- **Constants** — both `define()` and `const` declarations
- **Global variables** — `$DB`, `$CFG`, `$USER`, `$PAGE`, `$OUTPUT`, `$SESSION`, `$COURSE`, `$SITE`, and more with correct type annotations

All implementation bodies are stripped — only declarations and signatures are preserved.

## Versions

Each Moodle release branch and version tag has a corresponding branch/tag in this repository:

| This repository | Moodle source |
|---|---|
| Branch `MOODLE_403_STABLE` | Latest `MOODLE_403_STABLE` (updated weekly) |
| Branch `MOODLE_500_STABLE` | Latest `MOODLE_500_STABLE` (updated weekly) |
| Branch `master` | Latest Moodle `master` (updated weekly) |
| Tag `v4.3.2` | Moodle release `v4.3.2` (immutable) |
| Tag `v5.0.0` | Moodle release `v5.0.0` (immutable) |

## How It Works

Stubs are auto-generated by [bimoo](https://github.com/michaelmeneses/bimoo), an AST-based stub generator built with `nikic/php-parser`. A GitHub Actions workflow runs weekly to detect changes in the official Moodle repository and regenerate stubs as needed.
